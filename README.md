## 🏛️ Overview

This repository serves as the official archival space for the web and automation projects developed for the **Barony of the Sacred Stone**. It acts as a central library for scripts, web-based tools, automation systems, and informational infrastructure used to support the baronial populace.

---

## 📁 Project Directory

### [Baronial Social Tools](https://github.com/thepottedhistorian/Sacred_Stone_Digital_Archive/tree/main/baronial%20social%20tools)
The primary automation suite governing event digests, email communications, and Discord broadcasting.

### [Quartermaster Inventory Portal and Asset Hub](./Quartermaster%20Inventory%20Portal%20and%20Asset%20Hub/)
Contains:

- Google Apps Script backend (`Code.gs`)
- Frontend portal interface (`Index.html`)
- Project documentation (`README.gs`)
- Change history (`CHANGELOG.gs`)

### [Website Builds](./website%20builds/)
Archived and active website projects, templates, and deployment-ready builds used by the Barony of the Sacred Stone for public-facing web services.


### Planned Additions

Future directories will be added as new web projects, automation tools, and historical archives are digitized and incorporated into the repository.

## 📜 Stewardship Guidelines

This archive is maintained by the **Barony of the Sacred Stone Webministry**. All code, scripts, and digital assets hosted within this repository are intended to support the educational, administrative, and historical mission of the **Society for Creative Anachronism (SCA)**.

### Archive Standards

#### Security
Sensitive identifiers, credentials, API keys, and access tokens are maintained through secure configuration methods such as environment variables or Script Properties and are never stored in plaintext.

#### Documentation
Each project directory includes its own documentation files (`README.md`, `README.gs`, or equivalent) to ensure long-term maintainability and knowledge preservation.

#### Maintenance
Projects are reviewed and updated periodically to maintain operational functionality and compliance with current Kingdom and Society digital policies.
