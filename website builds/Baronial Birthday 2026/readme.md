## 📋 Project Overview

Welcome to the production repository for the **Baronial Birthday 2026** event site, maintained within the **Sacred Stone Digital Archive**. 

The site provides comprehensive information for attendees of the Baronial Birthday 2026 event, including timetables, class tracks, championship rules, merchant registration, land allocation guidelines, and interactive vector site maps.

* **Live Site Target:** [https://ssbb.atlantia.sca.org/2026/index.html](https://ssbb.atlantia.sca.org/2026/index.html)
* **Archive Path:** `Sacred_Stone_Digital_Archive / website builds / Baronial Birthday 2026`
* **Tech Stack:** Vanilla HTML5, CSS3, custom vector/HTML mapping engines, and static brand assets.
