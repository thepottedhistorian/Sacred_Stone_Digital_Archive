Welcome to the static website repository for the **Baronial Birthday 2026** event site, archived and maintained within the **Sacred Stone Digital Archive**.

This repository contains all HTML structure, stylesheets, interactive mapping documents, and asset files necessary to deploy the event site.

---

## 🏛️ Project Overview

The site provides comprehensive information for attendees of the Baronial Birthday 2026 event, including schedules, class tracks, martial activities, merchant setup, encampment guidelines, and site maps.

* **Archive Path:** `Sacred_Stone_Digital_Archive / website builds / Baronial Birthday 2026`
* **Tech Stack:** Vanilla HTML5, CSS3, static image assets, interactive vector/HTML maps.
* **Deployment:** Designed for static web hosting (GitHub Pages, GitLab Pages, or standard web server root).

## 🛠️ Usage & Local Development

1. **Clone or Download:** Retrieve the contents of this folder onto your local machine.
2. **Local Preview:** Open `index.html` directly in any web browser to navigate the site.
3. **Editing Styles:** Adjust global styles, colors, and layout structure in `style.css`.
4. **Updating Maps:** Modify `SSBB FINAL MAP.html` or replace `Revision_v2.png` for site layout updates.

---

## 📜 Archival & Maintenance Notes

* Ensure all file links use relative paths to preserve archival portability across different web roots.
* When updating event details, update both the specific sub-page (e.g., `schedule.html`) and the master landing page (`index.html`) if featured summaries are present.
