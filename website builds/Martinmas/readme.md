## 📋 Overview

This directory contains the production web build for **St. Martin's Proclamation (Martinmas)**, hosted in the Canton of Salesberie Glen within the Barony of the Sacred Stone.

The site is designed as a multi-page medieval scroll interface featuring custom heraldic borders, parchment texture styling, staff contact tables, timetable schedules, and martial/arts tournament documentation.

* **Live Site Target:** [https://sacredstone.atlantia.sca.org/martinmas/](https://sacredstone.atlantia.sca.org/martinmas/)
